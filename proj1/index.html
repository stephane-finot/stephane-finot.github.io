Project Overview

The images we work with in this project are comprised of gray-scale images representing the data captured by the camera for a specific color channel. The challenge arises when each of these color channel images were taken at slightly different times, which causes slight differences in the position of the camera at the time of the image being taken. If you were to try stacking the images right away, it would be misaligned and the final image would contain chromatic aberations. Thus, we need some pre-processing to align the images so that the different channels will line up properly to create a final image that does not have chromatic aberations.

Part 1: Single-scale Alignment

A basic way to align the images is to use a single-scale approach in which we shift the entire color channels across a range of offsets (+ or - 15 pixels)and compute a difference metric to determine which of the tested offsets have the best alignment. This metric can be computed in a few different ways, including using the L2 norm and Normalized Cross-Correlation. L2 norm, or Euclidean Difference, measures the difference between each pixel value in the two images and sums the squared differences, and finally takes the square root of the sum. The best alignment the L2 norm is the one that minimizes this calculated value. Normalized Cross-Correlation normalizes both images to have zero mean and a variance of one, which ensures that different lighting conditions do not affect the comparison method. Then, the metric is calculated by summing the pixel-wise products of the two images. The calculated metric is the normalized cross-correlation between the two images, so higher calcualted values mean better alignment with NCC. In this project, I used NCC due to its reliability across different lighting conditions. For these images, the offsets calculated using NCC and L2 norm were identical, so I only present the results of NCC in this section. To avoid calculations being skewed by the edges of the image, which may contain artifacts, I cropped the sides of the images before computing the difference metric. Part 2: Multi-Scale Alignment

Single-scale alignment works well for small images, as the range over which we test offsets accounts for a decent percentage of the image (30 pixel-range for a 300 pixel-wide image is 10% of the image width). However, for larger images, this range is a much smaller percentage of the image width, and most likely will not search enough offsets to find the best one as the misalignment is too large. Hence, we must find a way to narrow our search window so that we do not need to iterate over a huge window. We can do this through downsampling the image to make it a smaller size. Then, we can run our single-scale alignment on the downsampled image to find a good offset for the downsampled image. Then, use the offset of this downsampled image to find a smaller range of offsets to test on the full-size image. To make this more effective, I had this process run recursively where I continued downsampled until I reached a base case where the images were in a viable size for single-scale alignment. Through each iteration, you can test a range based off the recursive call below it as it will return an estimate offset. This will continuously pass up a range of offsets to keep testing optimal offsets until we eventually reach the full-resulution to test the image on.
