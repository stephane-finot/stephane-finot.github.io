Part 1.1: Convolutions from Scratch!

Here, I compare a 4-for loop based function, 2-for loop based function, and scipy's built in convolution function on a self portrait. For the 4-for loop, boundaries and padding were addressed through simply not adding the values of positions that land outside the image's bounds. This approach iterated through the indices of the output image with 2 for loops, and then used another 2 for loops to iterate through the pixels covered through the kernel in the original image. To clean it up for the 2-for loop based approach, I used numpy's pad function with the according amounts to surround the copy of the image with 0s for more straightforward processing. Then, I could iterate through the indices of the output image, and sum up the according sub-array in the padded copy with numpy functions. For runtime, the 4-for loop was the slowest (~24.3 seconds), followed by the 2-for loop (~1.6 seconds), and then the built in scipy.signal.convolve2d was significantly faster (rounded to 0.0s) than both of my implementations. The specific parameters were scipy.signal.convolve2d(im, blurKernel9, mode='same', boundary='fill', fillvalue=0) which fills the boundaries with 0s, mirroring my implemented padding.

The first set of images are using a 9x9 box filter. The finite difference filters were defined by Dx = [1, 0, -1] and Dy = [1, 0, -1]t which is transposed so that its a vertical kernel. 


            def convolution4loops(image, kernel):
                image = np.asarray(image, dtype=np.float32)
                kernel = np.asarray(kernel, dtype=np.float32)
                newImage = np.zeros((image.shape[0], image.shape[1]), dtype=np.float32)
                height = image.shape[0]
                width = image.shape[1]
                kernelFlipped = kernel[::-1, ::-1] #flipped
                for r in range(height):
                        for c in range(width):
                            currTotal = 0.0
                            for i in range(-(kernel.shape[0]//2), (kernel.shape[0]//2) + 1): 
                                for j in range(-(kernel.shape[1]//2), (kernel.shape[1]//2) + 1): 
                                    nx, ny = r + i, c + j
                                    if 0 <= nx < height and 0 <= ny < width:
                                        currTotal += image[nx][ny] * kernelFlipped[i + (kernel.shape[0]//2)][j + (kernel.shape[1]//2)]
                            newImage[r][c] = currTotal
                return newImage

            def convolution2loops(image, kernel):
                image = np.asarray(image, dtype=np.float32)
                kernel = np.asarray(kernel, dtype=np.float32)
                oldImagePadded = np.pad(image, ((kernel.shape[0]//2, kernel.shape[0]//2), (kernel.shape[1]//2, kernel.shape[1]//2)))
                newImage = np.zeros((image.shape[0], image.shape[1]), dtype=np.float32)
                height = image.shape[0]
                width = image.shape[1]
                kernelFlipped = kernel[::-1, ::-1] #flipped
                for r in range(height):
                        for c in range(width):
                            newImage[r][c] = np.sum(kernelFlipped * oldImagePadded[r:r + kernel.shape[0], c:c + kernel.shape[1]])
                return newImage

Part 1.3: Derivative of Gaussian (DoG) Filter

I created a gaussian (9 pixels, sigma = 3) and applied a blur to the image by convolving the image with the gaussian kernel to remove high-frequency noise. Then, I applied the same derivative kernels to build a gradient magnitude, and once again created a binarized edge image.

For differences, we can see that the resulting thresholded gradient has much less noise, while maintaining the main edges compared to without the blurring process. Furthermore, the edges are much thicker.

For the next section, we look at what happens when we use a Derivative of Gaussian (DoG) which means applying the derivative filter to our kernel before applying it to our image, creating a composite kernel that completes both blurring and taking the derivative in one pass.

As we can see, the outputs of blurring the image first, or taking the derivative of the gaussian, results in the same images. This is due to the associative property of convolutions.

Part 2: Fun with Frequencies

Part 2.1: Image Sharpening

Here I look at sharpening. Sharpening works by reducing the low frequency parts of the image to highlight the high frequency parts. The low frequency parts of the image are found by blurring the image. Then, we can subtract the low frequency regions from the original image to isolate the high frequency parts of the image. By multiplying the high frequencies, and adding it back to the original image, the result is the edges of the image being more defined, and a "sharper" image.

In this specific portion, we wanted to be able to apply this in a single convolution, so i subtracted a gaussian from a single spike to create a kernel that would subtract surrounding low frequencies and multiply high frequencies.

Note: The food image I used was a higher resolution than the taj, so the effects of blurring and sharpening are less pronounced as the kernel is relatively smaller.

As we increase the sharpening levels, the whites become brighter and become surrounded by darker surroundings. This is easiest to see in the light reflections seen on the clean and empty parts of the plate.

For testing purposes, I blurred an image and then resharpened the blurred image. We can see the image appears slightly sharper, but still does not recover the original pre-blur image. Information is lost when we blur it the first time, and this can never be recovered even through sharpening.

Part 2.2: Hybrid Images

By first aligning, and then layering the highpass of one image and the low pass of another image, we can get a hybrid image where we see the detail of the high pass image. Simultaneously, if you look from far away or blur your eyes, you can focus on the low pass image and see a different image. This method was based on the SIGGRAPH 2006 paper titled "Hybrid Images" by Oliva, Torralba, and Schyns.

I used a cutoff of 1 and 10 for the sigma values when calculating the kernel for high pass and low pass. This means the high pass was calculated with the original image minus an image blurred by a gaussian with sigma = 1, and the low pass image was calculated by blurring an image with a gaussian with sigma = 10. Additionally, I multiplied the high pass to make it clearer in the output.

Part 2.3: Gaussian and Laplacian Stacks

In this part, we create Gaussian stacks by blurring the image multiple times. The Laplacian stack is created through subtracting the current gaussian level by the next blurrier one, to get a difference in the detail. The mask on the right is what is used for blending.

Part 2.4: Multiresolution Blending

To blend two images, we can use a mask as a guide on how to blend the Laplacian at each level. Namely, we can multiply the same position pixel in the first image by the value in the mask, and add 1-mask value to get the weight of the second image. Since we blurred the mask as well in a gaussian stack, the mask gets smoother across the lower levels. This creates a smooth blend as we weigh across levels, with a sharper blend for more fine details and coarser blend for more coarse details. To create the blended image, adding the laplacian stack to the lowest gaussian level results in the original image. So we add the lowest gaussian masked level of each image, and add all of the laplacian levels to reconstruct the full image. I used the lowest mask level for the gaussian level as well.

What I Learned

The most important idea I learned was the idea of processing images across different domains. For example, by working with a different mask at different laplacian levels, we can have specific behavior that is more fit for the current pass of the image we are working with. Specifically in this case, it was sharper blends for finer detail, and smooth blend for coarser details.
